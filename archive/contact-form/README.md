# Contact Form (archived)

Retired `/contact` page, kept for reference. It posted the form to a small Nodemailer email server on Heroku, which has since been shut down.

This folder is outside `src/`, so none of it is built or deployed. The import paths in these files point to their old locations under `src/` and won't resolve from here.

- `ContactMe.jsx`: the page component (form state, axios POST, sending/sent/error states)
- `_contact.scss`: its styles
